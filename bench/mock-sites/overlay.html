F-03 · ELEMENT-ANCHORED OVERLAY PRIMITIVES

Overlay primitives gallery.

Deterministic targets for every primitive and every annotation state. All text here is synthetic.

One target per primitive

Fixed sizes and fixed order, so a browser test can assert geometry rather than pixels.

Annotation states

Detachable

Removed from the DOM by the driver.

Hidden

Toggled to display: none and to visibility: hidden.

Replaced

Re-annotated with a different primitive kind.

Multi

Three simultaneous annotations on one layer.

Viewport edges

Pinned to the edges so the positioner flips and clamps, and the arrow has a real leader to draw.

Page input

A real form control, so a test can prove the overlay does not intercept pointer, keyboard or focus events.

Nested scroll

Scrolls inside a container, not the page.
